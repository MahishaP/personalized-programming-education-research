# Personalized Programming Education Research

## 📚 Overview

This repository contains the research proposal and academic research work for my final year individual research project conducted as part of the Bachelor of Software Engineering Honours degree program at The Open University of Sri Lanka.

The research focuses on developing a personalized programming education platform by integrating adaptive learning methods and gamification techniques to improve student engagement and learning outcomes.

## 🎯 Research Objectives

* Identify adaptive learning methods used in programming education platforms
* Analyze learner needs and preferences
* Propose a personalized learning platform
* Improve student motivation using gamification techniques

## 🔍 Research Areas

* Adaptive Learning
* Gamification
* Programming Education
* Personalized Learning Systems
* Educational Technology
